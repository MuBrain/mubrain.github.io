# MuBrain #3 — Enterprise Brain: Memory, Agents, and Capacity for Action

## Intent

Move beyond the idea of an Enterprise Brain as a document repository and explore the mechanisms that allow an organization to mobilize its memory and agents to reason and act.

## Working questions

- What should an organization remember, and what should it forget?
- How should knowledge, decisions, people, processes, and agents be connected?
- How can provenance and context be preserved?
- How can a real improvement in organizational capability be measured?

## Format

MuBrain 5@7, from 5:00 p.m. to 7:00 p.m., 100% in person in Montreal. Date and venue to be confirmed.

## LinkedIn description

The Enterprise Brain should probably not be a gigantic knowledge base.

A brain does more than store information. It creates connections, learns, forgets, reinterprets, mobilizes context, and triggers action.

If we take that metaphor seriously, the arrival of AI agents fundamentally changes the way we can think about organizational intelligence.

This third MuBrain meetup will focus on the architecture of an Enterprise Brain.

What building blocks allow an organization to move from available memory to an organizational capacity to reason and act?

We will work in particular on the following questions:

• What should an organization remember, and what should it deliberately forget?  
• How should knowledge, decisions, people, processes, and agents be connected?  
• How can we prevent an agent from becoming a new black box isolated from the collective?  
• What roles do context, provenance, and governance play?  
• How do we know whether an organization is becoming genuinely more capable rather than simply better documented?

The objective of the meetup will be to connect the conceptual, organizational, and technical dimensions of the Enterprise Brain and identify hypotheses that can feed future MuBrain publications.
