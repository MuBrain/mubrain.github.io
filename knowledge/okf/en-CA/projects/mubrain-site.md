# MuBrain Website

The MuBrain website is built with Astro using the Velocity theme.

## Current decisions

- The GitHub repository is `MuBrain/mubrain.github.io`.
- The website is published with GitHub Pages.
- Deployment is performed with GitHub Actions.
- The starting theme is Velocity.
- The website's primary language is Canadian French.
- Canadian English is maintained as a human-reviewed translation.
- Spanish was removed to avoid a phantom language.
- The OKF knowledge base is located in the `knowledge/` folder.

## Important separation

Public Astro content lives in:

```text
src/content/
```

The reference knowledge base lives in:

```text
knowledge/okf/
```

Astro does not automatically publish the `knowledge/` folder. Public content can instead use `okfSource` to declare the OKF file that inspired it.

## Publishing conventions

- French routes have no prefix.
- English routes use `/en/`.
- Language metadata uses `fr-CA` and `en-CA`.
- Each article has a stable `translationKey` in both languages.
- `sourceOfTruth` is `true` only for Canadian French content.
- An English translation declares its origin with `translationOf`.
- An incomplete translation remains a draft and is neither published nor announced in `hreflang` links.

## Hosting

The website remains published at `https://mubrain.github.io` until the `mubrain.com` domain is configured. Because GitHub Pages is static, forms must use an external service rather than an Astro API route.

The public `/llms.txt` file is generated by Astro during every build. It gives AI agents a concise overview of the site and links to published content in accordance with the format proposed by `llmstxt.org`.

## Event management

MuBrain meetups are managed as a dedicated Astro collection and as reference OKF records.

Public content lives in:

```text
src/content/events/
```

The source of truth for each event lives in:

```text
knowledge/okf/fr-CA/events/
```

Each public event references its OKF record with `okfSource`.

The public routes are:

```text
/events/
/events/<slug>/
```

Events can be prepared in advance with `draft: true`. They are then hidden from the public site, which makes it possible to prepare descriptions, proposed dates, and LinkedIn links before confirmation.

OKF event records preserve, in particular:

- the intent of the meetup;
- working questions;
- format;
- LinkedIn description;
- registration and LinkedIn links;
- follow-up elements and publications that may result from the meetup.

The reference template is `knowledge/okf/templates/fr-CA/event.template.md`.
