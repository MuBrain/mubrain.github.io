# MuBrain Foundation

MuBrain is being rebuilt as a knowledge-oriented website.

The objective is not only to publish articles. It is to structure knowledge so that it can be read by humans, maintained in GitHub, deployed with Astro, and progressively used by AI agents.

This first page is intentionally simple. It serves to stabilize the content architecture before a structure inspired by the OKF format is fully introduced.

The next phase of the work will clearly distinguish the public website, editorial content, knowledge notes, and reference files intended for agents.
